# Nome do Projeto: SIGEP_EPI

## 📌 Escopo do Projeto

### Problema
Qual problema o sistema pretende resolver?
As informações da produção de EPIs podem estar espalhadas em planilhas, dificultando a organização, análise e acompanhamento dos dados de produção.

### Objetivo
Qual é o objetivo principal do sistema?
Desenvolver um sistema que permita importar planilhas de produção, selecionar os atributos que serão analisados e gerar relatórios e apresentações no Power BI.

### Público-alvo
Quem utilizará o sistema?
Supervisores e Operadores

### Solução
Como o sistema pretende solucionar o problema?
O sistema permitirá que o usuário importe uma planilha de produção, selecione os dados que deseja analisar e visualize as análises geradas. A partir dessas informações, será possível criar uma apresentação no Power BI.

### Principais funcionalidades
- Importação de planilhas
- Seleção dos atributos que serão analisados
- Geração de análises e gráficos
- Criação de apresentações no Power BI
- Visualização de indicadores da produção
